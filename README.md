# Yaeri / Яэри 🦊

Персональная восьмихвостая лисица — AI-помощница. Отвечает через модели **Cloud.ru Foundation Models**, хранит историю и долговременную память в локальной базе и умеет искать ответы в ваших документах (RAG).

## Запуск в Windows

1. Скачайте весь репозиторий через **Code → Download ZIP** и распакуйте его (или выполните `git clone`).
2. Дважды нажмите **`Yaeri.bat`**.
3. Сайт автоматически откроется в браузере по адресу вида **`http://127.0.0.1:49231/`**. Число порта выбирает сама Windows; оно будет другим при каждом запуске.
4. Для остановки закройте окно запуска или нажмите **Ctrl+C**.

**Python, Node.js и установка пакетов не требуются.** Нужна Windows 10/11 со встроенным Windows PowerShell 5.1 и браузером.

### Что предусмотрено

- Русский интерфейс и русские сообщения в окне запуска.
- Пути с пробелами и кириллицей: например, `C:\Пользователи\Мои проекты\Яэри`.
- Корректное использование кавычек в BAT-файле.
- Автоматический свободный порт (TCP 0) без ручной настройки.
- Адрес **127.0.0.1**: сайт доступен только на этом компьютере, не в локальной сети и не в интернете.
- Автоматическое открытие браузера. Если открыть браузер не удалось, адрес отображается в окне.
- Без ключа Cloud.ru работает демо-режим: сообщения хранятся в браузере (localStorage).
- Логотип проекта (`site/logo.svg`): лисица с восемью хвостами. При открытии страницы хвосты раскрываются веером.
- Настройки проекта: шестерёнка в правом верхнем углу открывает панель. В ней можно задать обращение, цвет оформления, размер текста, анимации, отправку по Enter и показ времени. Настройки хранятся в браузере.

### Если сайт не открылся

- Не закрывайте окно, которое открыл `Yaeri.bat`: в нём работает сервер.
- Скопируйте точный **«Адрес сайта»** из окна и откройте в браузере.
- Проверьте, что скачали **всю папку**, включая `launcher/start.ps1` и `site/index.html`.
- Если PowerShell заблокирован политикой организации, обратитесь к администратору. BAT использует `-ExecutionPolicy Bypass` только для запущенного процесса и не меняет политику компьютера.
- Если первый запуск прошёл, а вкладка закрыта, можно снова открыть адрес из окна BAT.

## Подключение Cloud.ru

1. Получите API-ключ в личном кабинете Cloud.ru (сервис Foundation Models).
2. Запустите `Yaeri.bat`. Если ключ ещё не задан, окно запуска попросит его вставить (Ctrl+V или правый клик, затем Enter). Символы при вводе не отображаются — так и должно быть.
3. Ключ сохраняется в `config\yaeri.config.json`. Этот файл в `.gitignore`: он не попадёт в git, а браузер его никогда не получает — все запросы к Cloud.ru идут через локальный сервер.

Вместо ввода можно скопировать `config\yaeri.config.example.json` в `config\yaeri.config.json` и вписать ключ в поле `apiKey`, либо задать переменную окружения `CLOUDRU_API_KEY`. Пустой Enter при запуске оставляет демо-режим без AI.

### Выбор модели

Список моделей подгружается из Cloud.ru (`/v1/models`) и показан в выпадающем списке над чатом. Выбор запоминается в браузере. Модель по умолчанию и прочие параметры задаются в `config\yaeri.config.json`:

| Поле | Значение |
|---|---|
| `chatModel` | модель по умолчанию для ответов |
| `chatModels` | дополнительные модели для списка, если Cloud.ru не отдал перечень |
| `embeddingModel` | модель эмбеддингов для RAG и памяти |
| `temperature`, `maxTokens` | параметры генерации |
| `historyTurns` | сколько последних реплик отправлять модели |
| `ragTopK`, `memoryTopK`, `minScore` | сколько фрагментов документов и памяти подмешивать и минимальная близость |
| `systemPrompt` | свой системный промпт; `{name}` заменяется обращением |

После правки файла перезапустите Яэри.

## База данных и RAG

Всё хранится локально в папке `data\` (в `.gitignore`), в виде JSON-файлов — без установки SQLite или других программ:

- `history.json` — переписка;
- `memory.json` — долговременная память: каждая пара «вопрос — ответ» с эмбеддингом;
- `docs.json` — загруженные документы, нарезанные на фрагменты, с эмбеддингами.

Как работает ответ: вопрос превращается в эмбеддинг (Cloud.ru), локальный сервер находит самые близкие фрагменты документов и прошлых разговоров (косинусная близость), добавляет их в системный промпт и отправляет модели вместе с последними репликами. Под ответом видно, какая модель отвечала и какие источники использованы.

Документы добавляются в **Настройки → Документы для RAG**. Поддерживаются текстовые файлы (`.txt`, `.md`, `.csv`, `.json`, `.html` и т. п.) до 1 000 000 символов; PDF и Word пока нужно сохранить как текст. Если сменить `embeddingModel`, появится кнопка «Переиндексировать».

В настройках также можно выключить RAG или запоминание и стереть память. «Очистить чат» удаляет переписку, но не память.

Резервная копия — просто скопируйте папку `data`.

## Структура

```text
Yaeri/
├── Yaeri.bat             # Запуск двойным кликом
├── launcher/
│   ├── start.ps1         # Локальный HTTP-сервер (PowerShell)
│   └── yaeri-api.ps1     # API: прокси к Cloud.ru, база, RAG
├── config/
│   └── yaeri.config.example.json  # Шаблон настроек (ключ — в yaeri.config.json)
├── data/                 # Создаётся при запуске: история, память, документы
├── site/
│   ├── index.html        # Русскоязычный интерфейс чата и настройки
│   └── logo.svg          # Логотип и значок вкладки
└── README.md
```

## Статус

Работает AI-чат через Cloud.ru с выбором модели, локальной памятью и RAG по документам. Голос и анимированный аватар будут добавляться отдельно.

Примечание: запуск требует Windows PowerShell 5.1; на macOS и Linux этот `.bat` не работает.
